# Contributing

## Workflow

1. Create a branch from `main`: `<type>/<short-description>` (e.g. `feat/invoice-export`, `fix/login-timeout`).
2. Commit using [Conventional Commits](https://www.conventionalcommits.org/) in English.
3. Open a pull request to `main` and fill in the template.
4. `evans-admin` reviews and merges. Do not push or merge to `main` directly.

## Conventions

- Code, comments, commit messages, READMEs and developer docs: English.
- Issues, discussions and user-facing documentation: Spanish.
- Labels: English names, Spanish descriptions.
- Never commit secrets, credentials or personal data. Use the repository's secret store instead.
